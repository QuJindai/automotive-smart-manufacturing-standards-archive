# Automotive Smart Manufacturing Standards Archive

Public download/verification infrastructure for **publicly redistributable** automotive smart-manufacturing standards assets.

## Purpose

This repository stores only:

- public-source download manifests;
- GitHub Actions download/verification workflows;
- SHA-256 manifests and archive status metadata;
- documentation for the Google Drive archival workflow.

It **does not commit standards PDFs or large source archives into Git history**. Downloaded assets exist only as short-lived GitHub Actions artifacts and are transferred to the long-term archive separately.

## Cost model

- Repository visibility: **Public**
- Runner: `ubuntu-latest`
- Artifact retention: **1 day**
- Long-term archive: Google Drive

## Copyright policy

Only documents/specifications that are officially published for public download and whose distribution terms permit this archival workflow are downloaded automatically. Copyright-restricted ISO/IEC/IATF/AIAG/VDA/SAE/etc. standards are represented by official acquisition links/metadata only; their full text is not redistributed here.
